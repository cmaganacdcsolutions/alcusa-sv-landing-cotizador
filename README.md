# ALCUSA — Landing + Cotizador

Landing única de ALCUSA (Expertos en Aluminio y Vidrio, El Salvador) que une alcusasv.com y la tienda,
con cotizador en línea (confirmación por WhatsApp o pago con Wompi) y formulario de contacto.

- `main` — versión estable (lo que se despliega en Hostinger).
- `dev` — todo el desarrollo; se integra a `main` cuando pasan las pruebas.

Desarrollado por CDC Software Solutions.
