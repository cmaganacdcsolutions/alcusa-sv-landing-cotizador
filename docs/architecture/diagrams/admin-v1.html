Secuencia: operador edita y publica una promocion

sequenceDiagram
  autonumber
  actor A as Operador
  participant N as Nginx
  participant S as Fastify (admin)
  participant D as MariaDB
  participant F as promotions.json
  actor V as Visitante

  A->>N: POST login (usuario + contrasena)
  N->>S: proxy (limit_req 5/min)
  S->>D: verificar argon2id, lockout, crear sesion stage=password_ok
  Note over S: nextStage(): ADMIN_MFA_MODE=off => active (v1.1: mfa_pending)
  S-->>A: Set-Cookie __Host- (HttpOnly, Secure, Strict) + CSRF en HTML

  A->>N: POST /promociones/12 (formulario + imagen, CSRF)
  N->>S: proxy
  S->>S: validar sesion active, CSRF, zod, sharp (tipo, 5 MB, WebP sin recorte)
  S->>D: UPDATE promotions (draft) + audit_log
  S-->>A: 302 lista (borrador, NO visible aun)

  A->>N: POST /promociones/12/publicar
  N->>S: proxy
  S->>D: GET_LOCK, tope de 3 activas por solape de fechas, status=published
  S->>D: SELECT hasta 3 activas
  S->>F: escribir tmp + rename (atomico, solo si cambia el hash)
  S-->>A: 302 "En la landing"

  V->>N: GET / (HTML estatico, fallback horneado)
  N-->>V: HTML
  V->>N: GET /api/promotions.json
  alt archivo valido
    N-->>V: 200 JSON (cache 60 s + SWR)
    Note over V: filtra por fecha SV y reemplaza tarjetas
  else falla o invalido
    Note over V: se conserva el fallback del build
  end
  Note over S,F: Timer cada 15 min regenera por vencimientos

Secuencia: publicar catalogo de productos

sequenceDiagram
  autonumber
  actor A as Operador
  participant S as Fastify (admin)
  participant D as MariaDB
  participant W as Worker catalog-build
  participant R as releases/ + symlink current
  actor V as Visitante

  A->>S: guardar producto (borrador) + imagen
  S->>D: products / product_images (draft), uploads en /media
  A->>S: POST Publicar catalogo (CSRF)
  S->>D: INSERT publish_jobs queued (GET_LOCK catalog_build)
  S-->>A: estado "en cola"
  W->>D: export catalog.generated.json (solo published)
  W->>W: astro build en directorio de trabajo
  W->>W: validar: zod, assertCatalogContent, conteo de paginas, product_slug de promos
  alt todo valido
    W->>R: rsync releases/ts + swap atomico del symlink
    W->>D: publish_jobs = published
    V->>R: GET /catalogo/slug (HTML estatico nuevo)
  else falla
    W->>D: publish_jobs = failed + log_tail
    Note over R: el sitio queda en la version previa
  end
  A->>S: ver estado del job
